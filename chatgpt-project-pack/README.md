# ChatGPT Project Instructions 朋友测试包

适用于 ChatGPT Project，以及其他支持“项目指令”“系统提示词”或“智能体设定”的 AI。

## 下载

[下载最新版 `chatgpt-parenting-assistant.zip`](https://github.com/VonnieW199304/baby-care-advisor/raw/refs/heads/main/chatgpt-project-pack/chatgpt-parenting-assistant.zip)

这个链接长期保持不变。后续更新会直接替换同一路径下的 ZIP，不需要更换分享链接。

## 最简单的用法

1. 下载并解压 ZIP。
2. 推荐分别建立三个 Project：宝宝行为与发育、观点鉴别与科学分析、消费决策。
3. 将对应的 `Project_Instructions.md` 全文粘贴到 Project Instructions。
4. 像平时一样直接提问；截图也可以直接发。
5. 需要反馈时，在原对话输入 `反馈`，检查隐私后把 AI 生成的反馈包转发给测试邀请人。

如果所用 AI 只能建立一个 Project，使用包内的 `04_单Project统一入口_Instructions.md`。

## 更新说明

固定下载链接可以避免每次换分享地址，但无法让已经粘贴的指令自动更新。版本升级后，用户仍需重新下载，并用新文件全文替换原来的 Project Instructions。

当前版本与 SHA-256 校验值见 [`VERSION.md`](VERSION.md)。
