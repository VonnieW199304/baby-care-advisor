# baby-care-advisor

面向 0 至 3 岁宝宝日常照护问题的 Agent Skill，覆盖行为、睡眠、喂养、发育、日常安全、照护计划、图片与截图，以及宝宝基础档案的首次填写和定期更新。

当前版本：`v0.2.0-beta.1`

## 它解决什么问题

- 信息不足时先给暂定判断、依据、低风险行动和观察重点，而不是只给一句动作或直接拒绝判断；
- 将最关键的缺失信息集中为最多 3 个问题；必要时只追加一轮新出现的关键分支；
- 信息补充完整后，整合为包含因素判断、当下行动、长期调整、观察标准和升级条件的具体方案；
- 复杂问题有证据才排主因、次因和维持因素；
- 急症、药物、疫苗、当前指南和安全问题采用更严格边界；
- 具名育儿方法先确认具体来源，不凭方法简称生成完整协议；
- 不把单张照片、一次测量或一项里程碑直接当成诊断。

## 公测状态

这是公开测试版，不是医疗产品，也不保证不同模型和宿主得到同样结果。

已观察到：

- 高能力模型能根据问题复杂度调整回答深度；
- 较弱模型即使加载 Skill，仍可能过长、加入无依据数字或没有完全执行因果边界；
- 部分 Agent 宿主会偶发不自动加载 Skill；
- 纯 Skill 无法提供宿主级的确定性安全校验。

因此公测期间推荐使用能力较强的模型，并在每个新对话中显式选择或调用 Skill。涉及急症、药物、剂量、疫苗、疾病、发育倒退或明显异常时，不能只依赖 AI 回答。

## 安装

### Codex

将本仓库目录放入：

```text
~/.codex/skills/baby-care-advisor/
```

### WorkBuddy 或支持 ZIP 导入的宿主

下载 GitHub Release 中的：

```text
baby-care-advisor-v0.2.0-beta.1.zip
```

在 Skill 管理页上传。若更新同名版本后仍加载旧规则，先卸载旧版，再安装新包。

不同宿主对 `agents/`、`references/` 和自动触发的支持可能不同。安装后先确认宿主实际保留了 `references/` 目录。

## 最短使用方式

每个新对话先显式选择“宝宝照护判断”，或输入：

```text
$baby-care-advisor 宝宝最近一放床上就醒，怎么办？
```

复杂问题可直接提出目标：

```text
$baby-care-advisor 请分析可能因素，并分别告诉我今晚和白天怎么做。证据不足时不要强行排主因。
```

## 宝宝基础信息

首次使用或需要更新时可以说：

```text
$baby-care-advisor 帮我建立宝宝基础档案，只问当前真正需要的信息。
```

```text
$baby-care-advisor 根据这段对话更新宝宝档案；先列出准备更新的字段和日期，等我确认后再写入。
```

通用 Skill 不包含任何真实儿童档案。档案只应保存在用户明确选择的本地项目或工作区中。

## 安全边界

- 不诊断、不处方、不替代急救、儿科或线下发育评估；
- 不只凭年龄计算药物剂量；
- 不凭旧记忆回答当前疫苗、指南、召回或产品安全事实；
- 不为改善睡眠而削弱安全睡眠要求；
- 不把一项新发育技能与同期问题的时间相邻直接写成主因；
- 急症回答不应附加未经当前权威来源支持的家庭处置。

如果 AI 的回答与当地急救、医生、药师或当前官方指南冲突，以专业人员和当前权威要求为准。

## 测试与已知限制

历史内部测试包括薄输入、连续追问、复杂夜醒、辅食拒绝、打人、未定义睡眠方法、急症、截图、观点与购买路由等代表场景。

`v0.2.0-beta.1` 重写了普通问题的交互协议，旧版模型测试结果不能直接视为新版通过。当前状态：

| 项目 | 结果 |
|---|---|
| 主规则静态反回归 | 通过；已移除一两句上限、默认不追问和输出删减门禁 |
| 包结构、YAML、引用目录、隐私扫描 | 通过 |
| 高能力模型回答质量 | 待运行新版有 / 无 Skill 对照 |
| 较弱模型硬安全指标 | 待运行新版回归 |
| 自动触发 | 宿主相关，公测仍建议显式调用 |

完整的模型内部推理和含儿童隐私的原始对话不进入公开仓库。

## 反馈

不需要自己整理测试报告。在出现问题的同一个对话中输入：

```text
反馈
```

AI 会让你从“有帮助、没解决问题、问得太多、回答机械、可能不安全”中选择一项，然后从紧邻的一轮问答生成可复制的匿名反馈包。它不会自动上传或发送内容；请检查隐私后直接转发给 Skill 提供者。

如果输入反馈时已经说明分类，例如：

```text
生成反馈包：没解决问题。
```

AI 应直接生成反馈包，不再追问。普通的“这个办法没用”仍按新的照护信息继续处理，不会自动切换成反馈模式。

技术用户也可以通过 [GitHub Issues](https://github.com/VonnieW199304/baby-care-advisor/issues/new/choose) 提交，并尽量保留：

- 平台与模型完整名称；
- Skill 版本；
- 是否显式调用；
- 是否联网或能读取图片；
- 匿名化后的完整对话；
- 具体问题属于安全、事实、过度追问、回答机械、没有解决问题或 Skill 未加载中的哪一类。

请删除儿童姓名、完整生日、地址、医院、学校、账号、照片和其他可识别信息。模型生成的匿名化结果仍需人工复核。
